# 核心代码类分析

## 1. BattleManager (战斗管理器)

### 1.1 服务端 BattleManager

**文件**: `Src/Server/GameServer/GameServer/Managers/BattleManager.cs`

```csharp
class BattleManager : Singleton<BattleManager>
{
    static long bid = 0;

    public void Init()
    {
    }

    public void ProcessBattleMessage(NetConnection<NetSession> sender, SkillCastRequest request)
    {
        Log.InfoFormat("BattleManager.ProcessBattleMessage: skill:{0} caster:{1} target:{2} pos:{3}", 
            request.castInfo.skillId, request.castInfo.casterId, 
            request.castInfo.targetId, request.castInfo.Position.String());
        
        Character character = sender.Session.Character;
        // 通过MapManager获取对应地图的Battle实例
        var battle = MapManager.Instance[character.Info.mapId].Battle;
        battle.ProcessBattleMessage(sender, request);
    }
}
```

**职责**:
- 接收战斗相关网络消息
- 根据玩家所在地图路由到对应的Battle实例
- 单例模式管理

**实现边界说明**:
- 当前路由键主要使用 `mapId`，若进入多实例地图（如竞技场），需要额外带上 `instanceId` 做精确路由。

### 1.2 客户端 BattleManager

**文件**: `Src/Client/Assets/Scripts/Managers/BattleMananger.cs`

```csharp
class BattleMananger : Singleton<BattleMananger>
{
    public delegate void TargetChangedHandler(Creature target);
    public event TargetChangedHandler OnTargetChanged;

    private Creature currentTarget;
    public Creature CreatureTarget { get { return currentTarget; } 
        set { this.SetTarget(value); } }
   
    private NVector3 currentPosition;
    public NVector3 CreaturePosition { get { return currentPosition; } 
        set { this.SetPosition(value); } }

    public void CastSkill(Skill skill)
    {
        if (!skill.Owner.IsCurrentPlayer) return;

        if (skill.CanCast(currentTarget) != SkillResult.Ok)
        {
            return;
        }

        int target = currentTarget != null ? currentTarget.entityId : 0;
        BattleService.Instance.SendSkillCast(skill.Define.ID, skill.Owner.entityId, target, currentPosition);
        
        if (skill.Owner.IsCurrentPlayer)
        {
            skill.Owner.CastSkill(skill.Define.ID, currentTarget, currentPosition);
        }
    }

    internal void ProcessBattleMessage(SkillHitResponse message)
    {
        foreach (var Hit in message.Hits)
        {
            var caster = EntityManager.Instance.GetEntity(Hit.casterId) as Creature;
            if (caster != null)
            {
                caster.DoSkillHit(Hit);
            }
        }
    }
}
```

**职责**:
- 管理当前目标选择
- 管理位置目标选择
- 发起技能施放请求
- 处理服务端返回的伤害消息

## 2. Battle (战场)

**文件**: `Src/Server/GameServer/GameServer/Battle/Battle.cs`

```csharp
class Battle
{
    public Map Map;
    Dictionary<int, Creature> AllUnits = new Dictionary<int, Creature>();
    Queue<NSkillCastInfo> CastActions = new Queue<NSkillCastInfo>();
    List<NSkillCastInfo> CastSkills = new List<NSkillCastInfo>();
    List<NSkillHitInfo> Hits = new List<NSkillHitInfo>();
    List<NBuffInfo> BuffsActions = new List<NBuffInfo>();
    List<Creature> DeahPool = new List<Creature>();

    public Battle(Map map)
    {
        this.Map = map;
    }

    public void ProcessBattleMessage(NetConnection<NetSession> sender, SkillCastRequest request)
    {
        Character character = sender.Session.Character;
        if (request.castInfo != null)
        {
            if (character.entityId != request.castInfo.casterId)
            {
                return;
            }
            this.CastActions.Enqueue(request.castInfo);
        }
    }

    public void Update()
    {
        if (this.CastActions.Count > 0)
        {
            NSkillCastInfo skillCast = this.CastActions.Dequeue();
            this.ExecuteAction(skillCast);
        }

        this.UpdateUnits();
        this.BroadcastHitsMessage();
        this.Hits.Clear();
        this.CastSkills.Clear();
        this.BuffsActions.Clear();
    }

    public void JoinBattle(Creature unity)
    {
        this.AllUnits[unity.entityId] = unity;
    }

    public void LeaveBattle(Creature unit)
    {
        this.AllUnits.Remove(unit.entityId);
    }

    public List<Creature> FindUnitsInRange(Vector3Int pos, int range)
    {
        List<Creature> result = new List<Creature>();
        foreach (var unit in this.AllUnits)
        {
            if (unit.Value.Distance(pos) < range)
            {
                result.Add(unit.Value);
            }
        }
        return result;
    }
}
```

**补充理解**:
- `Battle` 是服务端战斗聚合根，负责「动作入队 -> 结算 -> 广播」。
- `AllUnits` 中单位会被 `UpdateUnits` 推进，影响技能 CD、Buff、AI 行为。

**核心方法**:

| 方法 | 说明 |
|-----|------|
| `ProcessBattleMessage` | 接收技能施放请求并入队 |
| `Update` | 每帧处理战斗逻辑 |
| `ExecuteAction` | 执行施法动作 |
| `BroadcastHitsMessage` | 广播伤害/Buff消息 |
| `JoinBattle/LeaveBattle` | 管理战斗单位 |
| `FindUnitsInRange` | 查找范围内单位（AOE） |

## 3. Skill (技能)

### 3.1 服务端 Skill

**文件**: `Src/Server/GameServer/GameServer/Battle/Skill.cs`

**核心属性**:
```csharp
class Skill
{
    public NSkillInfo Info;
    public Creature Owner;
    public SkillDefine Define;
    public SkillStatus Status;
    private float cd = 0;
    private float castingTime = 0;
    private float skillTime = 0;
    private int Hit = 0;
    BattleContext Context;
    List<Bullet> Bullets = new List<Bullet>();

    public bool Instant { 
        get {
            if (this.Define.CastTime > 0) return false;
            if (this.Define.Bullet) return false;
            if (this.Define.Duration > 0) return false;
            if (this.Define.HitTimes != null && this.Define.HitTimes.Count > 0) return false;
            return true;
        }
    }
}
```

**核心方法**:

| 方法 | 说明 |
|-----|------|
| `CanCast` | 校验技能是否可以施放 |
| `Cast` | 施放技能 |
| `DoHit` | 执行命中逻辑 |
| `HitTarget` | 对单个目标造成伤害 |
| `HitRange` | AOE范围伤害 |
| `CalcSkillDamage` | 计算技能伤害 |
| `Update` | 更新技能状态 |
