# 战斗系统文档导航与阅读顺序

## 1. 文档目标

这套文档用于「系统梳理与知识回顾」，重点帮助你回答以下问题：

- 战斗系统整体架构怎么分层？
- 技能从点击到结算经历了哪些步骤？
- 属性、装备、Buff 如何影响最终伤害？
- 客户端到底负责什么，服务端又负责什么？
- 你如何判断系统的边界和可优化点？

## 2. 推荐阅读顺序

### 2.1 服务端主线

1. `01_核心架构系统.md`
2. `02_技能释放流程系统.md`
3. `04_Buff系统.md`
4. `03_属性与装备系统.md`
5. `05_核心代码类.md`

### 2.2 客户端补充视角

6. `06_客户端战斗架构.md`
7. `07_客户端技能表现流程.md`
8. `08_客户端目标选择与输入系统.md`
9. `09_客户端表现同步与校正.md`

### 2.3 最后复盘

10. `BattleSystem_CheatSheet.md`

> 建议：前 1~5 篇先建立服务端主链路与机制细节，6~9 篇补齐客户端视角，最后用速记卡做复盘。

## 3. 每篇文档用途

### 3.1 服务端文档

- `01_核心架构系统.md`：看系统边界、Tick 驱动、消息路由。
- `02_技能释放流程系统.md`：看完整时序和关键代码路径。
- `03_属性与装备系统.md`：看数值模型与属性分层。
- `04_Buff系统.md`：看生命周期、触发时机、服务端/客户端职责。
- `05_核心代码类.md`：按类名快速定位实现文件。

### 3.2 客户端文档

- `06_客户端战斗架构.md`：看客户端战斗模块怎么分层。
- `07_客户端技能表现流程.md`：看“发请求 + 本地先播 + 回包同步”的完整表现链。
- `08_客户端目标选择与输入系统.md`：看点选目标、位置技能和移动输入的关系。
- `09_客户端表现同步与校正.md`：看实体同步、技能回包、Buff 回包如何驱动表现对齐。

### 3.3 复盘文档

- `BattleSystem_CheatSheet.md`：3 分钟复习提纲。

## 4. 建议长期维护的四类信息

1. **事实层**：当前代码确实怎么运行，避免把“理想设计”和“实现现状”混淆。
2. **边界层**：已知约束与风险，比如吞吐、路由、多实例、同步误差等。
3. **客户端层**：哪些行为是本地预测，哪些必须等服务端回包。
4. **演进层**：你实际做过或计划做的优化，便于面试讲“问题-方案-结果”。

## 5. 快速自检清单（复盘用）

- 我能在 60 秒内讲清楚技能释放主链路。
- 我能解释为什么要“客户端先播 + 服务端权威结算”。
- 我能说清 `SkillHitResponse` 和 `BuffResponse` 分别驱动什么。
- 我能说清客户端为什么要跳过当前玩家自己的 `OnSkillCast` 回包。
- 我能指出至少 2 个当前实现边界，并给出优化方向。
