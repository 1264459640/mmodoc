# 核心代码类分析

## 1. ChatManager / ChatService

### 1.1 客户端 ChatManager

**文件**: `Src/Client/Assets/Scripts/Managers/ChatManager.cs`

**职责**：
- 维护聊天消息列表 `Messages`
- 维护发送频道与显示频道
- 维护当前私聊目标
- 通过 `OnChat` 通知 UI 刷新

**关键理解**：
- 它同时承担“消息缓存 + 显示过滤 + 私聊上下文”三类职责。

### 1.2 客户端 ChatService

**文件**: `Src/Client/Assets/Scripts/Services/ChatService.cs`

**职责**：
- 发送 `ChatRequest`
- 接收 `ChatResponse`
- 把不同频道消息转交给 `ChatManager`

### 1.3 服务端 ChatManager

**文件**: `Src/Server/GameServer/GameServer/Managers/ChatManager.cs`

**职责**：
- 维护世界/系统消息列表
- 按地图维护本地频道消息
- 按队伍、公会维护作用域消息池
- 提供增量读取接口

### 1.4 服务端 ChatService

**文件**: `Src/Server/GameServer/GameServer/Services/ChatService.cs`

**职责**：
- 接收 `ChatRequest`
- 私聊时走在线直推
- 群聊时写入 `ChatManager`

## 2. FriendManager / FriendService

### 2.1 客户端 FriendManager

**文件**: `Src/Client/Assets/Scripts/Managers/FriendManager.cs`

**职责**：
- 维护好友列表 `allFriends`

### 2.2 客户端 FriendService

**文件**: `Src/Client/Assets/Scripts/Services/FriendService.cs`

**职责**：
- 发送加好友请求与响应
- 发送删除好友请求
- 收到好友请求时弹确认框
- 收到好友列表更新后触发 UI 刷新

### 2.3 服务端 FriendManager

**文件**: `Src/Server/GameServer/GameServer/Managers/FriendManager.cs`

**职责**：
- 维护角色好友关系
- 生成 `NFriendInfo`
- 更新在线状态
- 在后处理阶段产出 `FriendListResponse`

### 2.4 服务端 FriendService

**文件**: `Src/Server/GameServer/GameServer/Services/FriendService.cs`

**职责**：
- 接收加好友请求并转发
- 接收响应后双边建立好友关系
- 处理删除好友逻辑

---

## 3. TeamManager / TeamService / Team

### 3.1 客户端 TeamManager

**文件**: `Src/Client/Assets/Scripts/Managers/TeamManager.cs`

**职责**：
- 接收新的 `NTeamInfo`
- 更新 `User.Instance.TeamInfo`
- 控制主界面队伍显示开关

### 3.2 客户端 TeamService

**文件**: `Src/Client/Assets/Scripts/Services/TeamService.cs`

**职责**：
- 发送组队邀请请求与响应
- 发送退出队伍请求
- 收到 `TeamInfoResponse` 后更新 `TeamManager`

### 3.3 服务端 TeamManager

**文件**: `Src/Server/GameServer/GameServer/Managers/TeamManager.cs`

**职责**：
- 维护全局队伍集合
- 根据角色查找所属队伍
- 负责组队创建与成员加入

### 3.4 服务端 Team

**文件**: `Src/Server/GameServer/GameServer/Models/Team.cs`

**职责**：
- 维护队长和成员列表
- 处理成员加入与离开
- 生成 `TeamInfoResponse`

### 3.5 服务端 TeamService

**文件**: `Src/Server/GameServer/GameServer/Services/TeamSeriuce.cs`

**职责**：
- 接收组队邀请请求并转发
- 接收邀请响应并建立队伍
- 处理离队逻辑

---

## 4. GuildManager / GuildService / Guild

### 4.1 客户端 GuildManager

**文件**: `Src/Client/Assets/Scripts/Managers/GuildManager.cs`

**职责**：
- 维护 `guildInfo` 与 `myMemberInfo`
- 提供 `HasGuild` 判定
- 按公会状态决定打开哪个 UI

### 4.2 客户端 GuildService

**文件**: `Src/Client/Assets/Scripts/Services/GuildService.cs`

**职责**：
- 发送创建、申请、离开、列表、管理命令请求
- 接收入会申请并弹审批框
- 收到 `GuildResponse` 后更新 `GuildManager`

### 4.3 服务端 GuildManager

**文件**: `Src/Server/GameServer/GameServer/Managers/GuildManager.cs`

**职责**：
- 启动时加载全部公会
- 维护全局公会字典
- 处理创建公会与名称校验
- 提供公会列表查询

### 4.4 服务端 Guild

**文件**: `Src/Server/GameServer/GameServer/Models/Guild.cs`

**职责**：
- 处理申请、审批、成员增删
- 生成 `NGuildInfo`
- 处理公告、晋升、转让等管理命令

### 4.5 服务端 GuildService

**文件**: `Src/Server/GameServer/GameServer/Services/GuildService.cs`

**职责**：
- 接收创建、列表、申请、退出、管理命令请求
- 转发会长审批请求
- 驱动 `GuildManager / Guild` 完成状态变更

---

## 5. UI 核心类

### 5.1 UIChat

**文件**: `Src/Client/Assets/Scripts/UI/UIChat/UIChat.cs`

**职责**：
- 展示聊天文本
- 切换显示频道与发送频道
- 管理私聊对象显示
- 处理玩家超链接点击

### 5.2 UIFriends

**文件**: `Src/Client/Assets/Scripts/UI/Friends/UIFriends.cs`

**职责**：
- 展示好友列表
- 作为私聊、组队、删除好友、挑战的入口

### 5.3 UITeam

**文件**: `Src/Client/Assets/Scripts/UI/Team/UITeam.cs`

**职责**：
- 展示当前队伍成员和队长
- 发起退出队伍请求

### 5.4 UIGuild

**文件**: `Src/Client/Assets/Scripts/UI/Guild/UIGuild.cs`

**职责**：
- 展示公会成员与信息
- 根据职位显示不同管理按钮
- 发起踢人、晋升、公告等管理操作

## 6. 快速记忆版

如果只记最关键的类，可以记这几组：

| 类 | 一句话定位 |
|---|---|
| `ChatManager` | 聊天消息与频道状态中心 |
| `ChatService` | 聊天通信入口 |
| `FriendManager` | 好友列表中心 |
| `FriendService` | 好友请求与列表同步入口 |
| `TeamManager` | 客户端队伍显示状态中心 |
| `Team` | 服务端临时队伍对象 |
| `GuildManager` | 客户端公会入口 / 服务端全局公会索引 |
| `Guild` | 服务端公会领域对象 |
| `UIFriends` | 多个社交入口汇聚点 |
| `UIGuild` | 公会管理表现层 |
